How to run this

Test the deployed app (not a file:// copy — Planning Center won't connect over file://). Run the Smoke test first; if it fails, stop and note it.

The green “✓ audited in code” items were verified by Claude reading and headlessly running the source — the logic is correct, so they're pre-marked Pass and you can skip them. Everything still To-do needs a human on a device: visuals, print preview, touch/drag, responsive layout, and the live Planning Center sign-in. Tap the To-do filter to see only what's left for you.

Cover the same flow on a laptop, the booth tablet in landscape and portrait, and a phone. A section isn't done until it passes on the tablet — that's the live context.

When something's wrong, mark the item Fail and tap note to jot the exact steps, what you expected, what happened, the device/browser, and whether a reload fixes it. Then tap Export findings and send the failures back for fixing.

After each batch of fixes, re-run the Smoke test + Regression watchlist to catch anything that broke.
